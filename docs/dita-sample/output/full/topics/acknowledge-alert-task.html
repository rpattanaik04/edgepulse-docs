Acknowledge an alert

Record that you reviewed an alert, so that other operators know it is handled.

You are signed in to the EdgePulse dashboard.

Acknowledge an alert only after you have reviewed the device that raised it. The acknowledgement records your client ID and the time.

Tip:
As an administrator, you can also delete a device that keeps raising alerts and has been retired. Deleting a device deletes its alerts.
  1. Select Refresh.
    The Alerts table shows the latest alerts.
  2. In the Alerts table, find the alert and read its severity, device and message.
  3. In the Devices table, select the device and review its latest readings.
    A vibration value above 5.0 mm/s is shown in red.
  4. In the alert row, select Acknowledge.
    A green message confirms the acknowledgement.

The alert state changes to acknowledged. The row shows your client ID, and the Open alerts counter decreases by one.

If new alerts keep arriving for the same device, set its status to maintenance while you investigate.
