Alert severity levels

Each alert has one of three severity levels. The level tells the operator how urgently to act.

Severity levels

Severity Meaning Operator action
critical A reading is beyond a safety limit. Review the device immediately.
warning A condition needs attention, for example a device stopped reporting. Check the device soon.
info An event that needs no action, for example a firmware update. No action is needed.

Automatic alert rule

The platform applies one automatic rule.

PropertyValueDescription
Measurementvibration_mm_sThe reading that the rule checks.
Limit5.0 mm/sA reading above this value raises an alert. The limit cannot be configured.
