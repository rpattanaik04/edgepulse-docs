Register a device

Add a device to EdgePulse so that it can send readings and raise alerts.

You are signed in to the dashboard.

A new device starts with the status offline. It becomes online when it sends its first reading.

Warning:
The demo API keeps data in memory. When the server restarts, all data returns to the original demo set.
  1. Select Add device.
  2. Enter the device details.
    Field Rule
    Name 3 to 64 characters.
    Site 2 to 64 characters.
    Protocol MQTT, OPCUA or MODBUS.
    Firmware The installed version. The default is 1.0.0.
  3. Select Register.
    A green message confirms the registration, and the device appears in the Devices table.

The device has the status offline until it sends a reading.
