# Glossary

Last updated: 2026-11-21

| Term | Definition |
|---|---|
| **Acknowledge** | To record that an operator reviewed an alert. EdgePulse stores the client ID and the time. |
| **Alert** | A notice that EdgePulse raises when a device needs attention. It has a severity and a state. |
| **Bearer token** | A temporary access code that you send in the `Authorization` header. |
| **Bridge** | A script that moves messages from one system to another. The MQTT bridge forwards MQTT messages to the REST API. |
| **Broker** | An MQTT server that receives messages and delivers them to subscribers. |
| **Client ID / client secret** | The credentials that identify an application when it requests a token. |
| **conref** | A DITA mechanism that reuses a block of content from another topic. |
| **Critical** | The highest alert severity. A reading is beyond a safety limit. |
| **Dashboard** | The browser interface for viewing devices, readings and alerts. |
| **Device** | A piece of monitored equipment, or the gateway attached to it. |
| **DITA** | Darwin Information Typing Architecture. An XML standard for structured technical content. |
| **Docs-as-Code** | A method that manages documentation with the tools of software development: plain-text files, version control and automated builds. |
| **Edge device** | A device at the site of the equipment that collects and sends readings. |
| **Endpoint** | A URL path of the API that performs one operation, such as `/api/v1/devices`. |
| **IIoT** | Industrial Internet of Things. Connected machines and sensors in industry. |
| **keyref** | A DITA mechanism that inserts a value defined once in a key map. |
| **MQTT** | A lightweight publish-and-subscribe messaging protocol for devices. |
| **OpenAPI** | A standard format that describes a REST API. |
| **Operator** | A user who monitors devices and acknowledges alerts. |
| **REST API** | An interface that uses HTTP requests to read and change data. |
| **Severity** | The urgency of an alert: `critical`, `warning` or `info`. |
| **Telemetry** | Readings that a device sends, such as temperature, vibration and pressure. |
| **Token lifetime** | How long a token stays valid. In EdgePulse, 3600 seconds. |
